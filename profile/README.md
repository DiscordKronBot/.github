### ✨ What Kron does

| | |
|---|---|
| 🎫 **Tickets** | Button or menu panels, questions before opening (text or dropdowns), naming rules, web transcripts, auto-close |
| 📝 **Forms & whitelist** | Web forms with a role pipeline and review buttons, ready-made templates |
| 🛡️ **Safety** | Moderation, Discord AutoMod presets, anti-raid, honeypot trap channel, Carl-style logs |
| 🧑‍⚖️ **Roles** | Role presets for staff without Manage Roles, owner-only role backups that repair a damaged server |
| 📨 **Invites** | Who invited whom, join messages and a leaderboard |
| 🎮 **Community** | Levels & economy, 11 games with bets, giveaways, birthdays, custom commands & tags |
| 🏗️ **Server tools** | Channel builder with server packs, beautify names, channel counters, welcome cards |
| 🔴 **Alerts** | Twitch, Kick and GitHub feeds posted as clean embeds |
| 🚓 **FiveM** | In-game bridge: character profiles in tickets, unstuck, garage, `/report`, job channels |
| 🏷️ **Whitelabel** | Run Kron under your own bot name and avatar |

Everything is set up from the **[dashboard](https://kronbot.xyz/dashboard)**, in **English or French**. No commands to memorize.

### 🤝 Join the team

Kron is growing and we are building a small team. Roles we are opening:

| Role | What you do |
|---|---|
| 🙋 **Helper** | Answer members in support tickets and #bot-support |
| 🔨 **Moderator** | Handle reports and keep the support server friendly |
| 📣 **Community manager** | Announcements, events, social media |
| 🎨 **Designer** | Website, dashboard, banners and emojis |
| 🧩 **Module developer** | Build and improve Kron's modules (Node.js, discord.js, React) |
| ⚡ **Performance** / 🔐 **Security** | Make Kron faster, safer and ready to scale |

Interested? Open a ticket on our **[Discord](https://kronbot.xyz/support)** and tell us what you would like to do.

**For developers:** you work on your own machine with your own test bot and a local database full of fake data (Docker), never on production. Branch from `dev`, open a pull request, automatic checks run on every pull request, and the owner reviews and ships. Team members find the full guide in `CONTRIBUTING.md` of the main repository.
